# Китай · учёт

Программа учёта закупок товаров из Китая: партии с товарами, авансы и долги поставщикам, инвесторы с долями.

## Как запустить
Двойной клик по **`Запустить.command`** — откроется браузер на http://localhost:8902

**Вход:** логин `admin`, пароль `china2026`

## Где данные
- база — файл `china.db` в этой папке (можно копировать как обычный файл);
- резервные копии — папка `backups/`, создаются сами при каждом запуске, хранятся 30 последних.

## Как пользоваться
1. «Магазины» → добавить свои магазины (номер + название).
2. «Поставщики» → добавить поставщиков (город нужен для маршрута на карточке партии).
3. «Партии» → «+ Новая партия»: дата, поставщик, аванс и список товаров — у каждого товара свой магазин.
4. Статус меняется кликом по цветной метке прямо в списке; даты отправки/прибытия проставляются сами.
5. «Сводка» — вся картина: долги, ожидаемые прибытия, закупки по месяцам. Там же экспорт в Excel.
