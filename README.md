# Китай · учёт

Программа учёта закупок товаров из Китая: партии с товарами, платежи, авансы и долги поставщикам, инвесторы с долями.

## Как запустить
Двойной клик по **`Запустить.command`** — откроется браузер на http://localhost:8902

**Вход:** логин `admin`, пароль `china2026`

## Где данные
- база — файл `china.db` в этой папке (можно копировать как обычный файл);
- резервные копии — папка `backups/`, создаются сами при каждом запуске, хранятся 30 последних.

## Как пользоваться
1. «Магазины» → добавить свои магазины (номер + название).
2. «Поставщики» → добавить поставщиков (город нужен для маршрута на карточке партии). Клик по строке — карточка поставщика: оборот, отдано, долг, партии и платежи.
3. «Партии» → «+ Новая партия»: дата, поставщик, аванс и список товаров — у каждого товара свой магазин.
4. Статус меняется кликом по цветной метке прямо в списке; даты отправки/прибытия проставляются сами.
5. «Платежи» → «+ Платёж»: аванс / доплата / возврат поставщику, можно привязать к партии. Как только по партии есть хоть один платёж, оплата по ней считается по платежам (ручной аванс переносится в платежи автоматически), долг поставщика пересчитывается сам.
6. «Сводка» — вся картина: статусы, топ поставщиков, магазины, долги, ожидаемые прибытия. Экспорт в Excel — там же и в «Настройках».

Горячие клавиши: `N` — новая запись, `/` — поиск, `⌘S` — сохранить окно, `Esc` — закрыть, `1…6` — разделы.

## Из чего состоит
- `server.py` — сервер и вся логика (стандартная библиотека Python, SQLite);
- `web/index.html` — разметка, `web/app.css` — стиль «тёмное стекло», `web/app.js` — интерфейс.
