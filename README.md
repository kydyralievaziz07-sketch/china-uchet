# Китай · учёт

Программа учёта закупок товаров из Китая: партии с товарами, платежи, авансы и долги поставщикам, инвесторы с долями.

## Две версии — одна программа
- **Облако:** https://china-uchet.onrender.com — с любого телефона и компьютера. **Пароль вводить не нужно:** один раз открываете свою личную ссылку `…/?k=КЛЮЧ` (она в «Настройки → На телефон»), и устройство помнит вход год. Логин с паролем остался только как запасной вход и для помощника. Данные в Postgres (Supabase), хостинг Render — оба на бесплатных тарифах. Бесплатный Render засыпает после 15 минут тишины, программа сама себя будит раз в 10 минут; если всё же уснул — первое открытие займёт ~30 секунд.
- **Локально:** двойной клик по **`Запустить.command`** → http://localhost:8902, без пароля, данные в файле `china.db`.

Перенос данных между ними: «Настройки → Скачать .db» на одной стороне и «Настройки → Загрузить базу из файла .db» на другой (пользователи при этом не трогаются).

## Где данные
- база — файл `china.db` в этой папке (можно копировать как обычный файл; «Настройки → Вся база одним файлом» скачивает его же);
- резервные копии — папка `backups/`, создаются сами при каждом запуске, хранятся 30 последних.

## Как пользоваться
1. «Магазины» → добавить свои магазины (номер + название).
2. «Поставщики» → добавить поставщиков (город нужен для маршрута на карточке партии). Клик по строке — карточка: оборот, отдано, долг, партии и платежи.
3. «Партии» → «+ Новая партия»: дата, поставщик, аванс и список товаров — у каждого товара свой магазин. Фильтры: период, магазин, поставщик, статус, поиск; сортировка; Excel по текущему фильтру.
4. Статус меняется кликом по цветной метке прямо в списке; даты отправки/прибытия проставляются сами.
5. Меню «⋯» у партии: дублировать · **разделить** (пришла половина — отмеченные товары уходят в новую партию, аванс делится пропорционально или переносятся выбранные платежи) · **закрыть партию** (ввести прибыль) · вложение инвестора · удалить.
6. «Платежи» → «+ Платёж»: аванс / доплата / возврат поставщику, можно привязать к партии. Как только по партии есть платёж, оплата считается по платежам (ручной аванс переносится сам), долг поставщика пересчитывается.
7. «Инвесторы» → «+ Вложение»: в конкретную партию или в общий пул; условие — доля от прибыли (%) или процент в месяц. Когда партия закрыта с прибылью, доли начисляются сами. «+ Выплата» — доля прибыли или возврат тела. Кнопка «Отчёт» — страница на печать / PDF для инвестора.
8. «Сводка» — вся картина за период: статусы, топ поставщиков, магазины, долги, прибытия, обязательства перед инвесторами.

Горячие клавиши: `N` — новая запись, `/` — поиск, `⌘S` — сохранить окно, `Esc` — закрыть, `1…6` — разделы.

## Как считаются доли инвесторов
- **Доля от прибыли, адресно в партию:** прибыль партии × процент инвестора. Начисляется после закрытия партии.
- **Доля от прибыли, общий пул:** доля инвестора в пуле = его вложение ÷ все вложения в пул. От прибыли каждой закрытой партии **без адресных вложений**, закрытой после даты вложения, он получает свой процент × долю пула.
- **Фиксированный процент:** вложение × процент × число полных месяцев с даты вложения (до даты возврата, если указана).
- К выплате = начислено − выплачено долей. Тело вложения возвращается отдельным типом выплаты.

## Голосовой ввод из Telegram
Бот **@Kitaibizmartbot**. Наговариваете голосовое обычными словами — по-кыргызски, по-русски, вперемешку или по-китайски — бот сам заполняет учёт и отвечает, что записал.

«Гуанчжоудан Чен, биринчи магазинге фен алдым, он штук, ар бири отуз доллар, аванс жүз доллар бердим, он күндөн кийин келет» → партия с товаром, аванс, долг 200 $, дата прихода 13.09.

У помощника **полный доступ к данным**: он делает всё, что вы делаете руками на сайте — заводит и правит партии, товары, магазины и поставщиков, ведёт платежи (аванс, доплата, возврат) и долги, инвесторов, вложения и выплаты, меняет статусы «вышла / пришла», закрывает партии с прибылью, исправляет и удаляет любые записи, отвечает на вопросы цифрами из базы. Закрыты только восстановление базы из файла и управление пользователями — это руками на сайте. Команды: `/итоги` `/долги` `/партии` `/помощь`.

Как это устроено: голос → Whisper на Groq (две расшифровки сразу, бесплатно) → модель с вашим справочником имён и магазинов → чтение и запись через те же `/api/…`, что и на сайте. Под каждым ответом кнопка «↩️ Отменить». Имена подбираются по звучанию («Ли Вэй ага» → поставщик «Ли Вэй»), незнакомые заводятся сами; суммы в юанях, сомах, тенге переводятся в валюту партии по курсу дня.

Управляет только владелец (его id в `KN_TG_ALLOW`), чужим бот отвечает отказом. В группе бот слушает только свою тему (`KN_TG_THREAD`), чтобы не мешать другой переписке; чтобы он видел голосовые в группе, его нужно сделать администратором.

## Из чего состоит
- `server.py` — сервер и вся логика: стандартная библиотека Python + SQLite локально, Postgres через pg8000 в облаке (переключается переменной `DATABASE_URL`);
- `web/index.html` — разметка, `web/app.css` — стиль «тёмное стекло», `web/app.js` — интерфейс;
- `tgbot.py` — голосовое управление через Telegram: расшифровка речи, разбор смысла, запись через своё же API;
- `render.yaml`, `requirements.txt` — облачная сборка. Код на GitHub: https://github.com/kydyralievaziz07-sketch/china-uchet (публичный, секретов в нём нет — всё в переменных окружения Render).

## Переменные окружения облака
`DATABASE_URL` (строка подключения Supabase, session pooler :5432) · `KN_PG_SCHEMA=china` · `KN_AUTH=1` (сессия обязательна) · `KN_OPEN_KEY` (ключ личной ссылки — вход без пароля) · `KN_ADMIN_PASSWORD` (запасной пароль владельца, применяется при старте) · `KN_SECRET` (подпись сессий) · `KN_KEEPALIVE_URL` (самопробуждение) · `PYTHON_VERSION` · для бота: `KN_TG_TOKEN`, `KN_TG_SECRET` (подпись вебхука), `KN_TG_ALLOW` (id владельца), `KN_TG_HOOK_URL`, `KN_AI_KEY` (ключ Groq), необязательный `KN_TG_THREAD` (слушать одну тему группы).

## Вход без пароля — как это устроено
Открытие `https://…/?k=КЛЮЧ` ставит подписанную cookie на 365 дней и убирает ключ из адресной строки. Дальше программа открывается сразу. В манифесте намеренно нет `start_url`: иконка на домашнем экране запоминает адрес вместе с ключом, поэтому приложение на телефоне тоже входит само. Ключ действует как пароль — не пересылать посторонним; сменить можно, поменяв `KN_OPEN_KEY` на Render (старые ссылки перестанут работать, уже вошедшие устройства останутся).

## Помощник
Владелец создаёт помощника в «Настройки → Пользователи». Помощник заводит партии, товары (без цен), магазины и поставщиков, меняет статусы и делит партии. Он не видит сумм, платежей, инвесторов и сводки, не может ничего удалять — это проверяется на сервере, а не только в интерфейсе.
